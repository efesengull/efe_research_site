Veri Çalışma Modları

İzleme verisi ile karar verisini ayıran iki katman.

Widget katmanı hızlı bağlam sağlar. Portföy ve değerleme hesaplarını güncelleyen API katmanı ise lisanslı ve zaman damgalı veri bekler.

API Entegrasyon Alanı

Lisanslı veri için güvenli sunucu proxy mimarisi hazır.

API anahtarları statik HTML içine yazılmaz. Tarayıcı yalnızca aynı alan adındaki güvenli quote endpoint'ine bağlanır.
